# Güvenlik

Kaçakçıdan’da olası bir güvenlik açığı bulduysanız ayrıntıları herkese açık issue veya pull request olarak yayımlamayın. Bildirimi `teskilatsiz@dev.com` adresine gönderin.

E-postada etkilenen ekranı veya dosyayı, sorunu yeniden oluşturma adımlarını ve olası etkisini belirtin. Gerçek kullanıcı verilerini, parolaları veya erişim anahtarlarını eklemeyin.

Yalnızca `main` dalındaki güncel sürüm takip edilir. Eski sürümlere yönelik güvenlik düzeltmesi yayımlanmaz.
